ACCESSIBILITY NOTES

Make the signal legible.

The page uses expressive type and motion, but its information should remain available to keyboard users, screen readers, small screens, and people who ask the system to reduce motion.

BUILT-IN PRACTICES

Structure before spectacle.

01 / 03

Landmarks

Each page has a skip link, header navigation, a main landmark, a footer, labelled navigation, and a meaningful document title.

Keyboard

Links and the theme button are native controls with visible focus outlines. The page does not require pointer gestures.

Contrast

Body copy uses dark ink on warm paper or pale ink on charcoal. Accent colors are not the only way meaning is conveyed.

MOTION

Quiet by request.

02 / 03

There is a slow paper-grid drift, a small fuse flicker, and scroll reveals for panels. If your system has prefers-reduced-motion: reduce enabled, animations and smooth scrolling are disabled in CSS. The page remains complete when JavaScript is blocked.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
  }
}

IF SOMETHING MISSED

Send a precise note.

03 / 03

Describe the page, device, browser, keyboard or assistive technology, and the exact obstacle. A focused report is easier to reproduce than “the page feels weird.”
